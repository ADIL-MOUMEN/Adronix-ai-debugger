# Adronix-ai-debugger
📌 Description

Adronix is a Python-based debugging assistant that analyzes code and detects common errors with explanations and fixes.

🚀 Features
Detects syntax errors (missing colon, print issues)
Identifies logic mistakes (assignment vs comparison)
Checks indentation problems
Supports multi-line code input
🧠 How it works

Adronix processes code line by line using rule-based analysis.

▶️ Usage
python main.py

Paste your code and type END to analyze.
